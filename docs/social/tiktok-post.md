## Before posting

- Add a trending sound in the TikTok editor (the file ships silent on purpose; licensed trending audio can only be attached in-app). Set its volume so the first beat lands on the cut to Glacier Point, about 3 seconds in.
- Put thetalusfieldjournal.com in the bio link; TikTok does not make caption URLs clickable.
- Cover frame: the first frame (Tunnel View with "Yosemite, planned right.").
- Post between 6 and 9 pm Pacific, and reply to early comments in the first hour.
